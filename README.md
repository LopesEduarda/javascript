# JavaScript do Básico ao Avançado 🚀

Este repositório é um guia completo de estudos de JavaScript, organizado por tópicos, com explicações, exemplos práticos e exercícios resolvidos.


## 📚 Conteúdo

- **01-variaveis-tipos.js**: Variáveis e Tipos de Dados
- **02-operadores.js**: Operadores
- **03-controle-fluxo.js**: Estruturas de Controle (if, switch, loops)
- **04-funcoes.js**: Funções
- **05-arrays.js**: Arrays
- **06-objetos.js**: Objetos
- **07-callbacks.js**: Callbacks
- **08-promises-async.js**: Promises e Async/Await
- **09-strings.js**: Manipulação de Strings
- **10-datas.js**: Manipulação de Datas
- **11-erros.js**: Manipulação de Erros
- **12-es6plus.js**: Recursos Modernos (ES6+)
- **13-metodos-uteis.js**: Métodos úteis de Arrays e Objetos
- **14-json.js**: JSON

Cada arquivo contém:
- Explicação teórica
- Exemplos comentados
- Exercícios práticos com resolução e explicação
